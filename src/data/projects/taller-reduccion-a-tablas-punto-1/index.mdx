## Descripción

Este trabajo corresponde al **Punto 1 del Taller de Reducción a Tablas** de la asignatura **Bases de Datos 1**. El dominio del ejercicio es un sistema editorial y de almacén: autores escriben libros, editores editan libros, libros se almacenan en almacenes, libros se incluyen en cestas de compra y clientes poseen cestas.

## Entidades del modelo base

| Entidad | Atributos | Clave primaria |
|---------|-----------|----------------|
| **AUTOR** | nombre1, nombre2, apellido1, apellido2, calle, carrera, número_dirección, URL | ID_autor |
| **EDITOR** | nombre1, nombre2, apellido1, apellido2, calle, carrera, número_dirección, teléfono, URL | ID_editor |
| **LIBRO** | año, título, precio, ISBN | ISBN |
| **CLIENTE** | nombre1, nombre2, apellido1, apellido2, calle, carrera, número_dirección, correo_electrónico, teléfono | — |
| **CESTA_DE_LA_COMPRA** | IDcesta | IDcesta |
| **ALMACÉN** | código, calle, carrera, número_dirección, teléfono | código |

## Relaciones del modelo base

Las relaciones del MER son todas muchos-a-muchos (M:N):

- **crear / escribir**: AUTOR ↔ LIBRO
- **editar**: EDITOR ↔ LIBRO
- **contener**: LIBRO ↔ CESTA_DE_LA_COMPRA (y LIBRO ↔ ALMACÉN)
- **tener**: CLIENTE ↔ CESTA_DE_LA_COMPRA

## Reducción a tablas (resolución)

Cada relación M:N se transformó en una **tabla intermedia** con clave primaria compuesta:

| Tabla intermedia | Clave primaria | Claves foráneas |
|------------------|----------------|-----------------|
| **AUTOR_LIBRO** | (ID_autor, ISBN) | ID_autor → AUTOR, ISBN → LIBRO |
| **EDITOR_LIBRO** | (ID_editor, ISBN) | ID_editor → EDITOR, ISBN → LIBRO |
| **LIBRO_CESTA** | (ISBN, IDcesta) | ISBN → LIBRO, IDcesta → CESTA_DE_LA_COMPRA |
| **LIBRO_ALMACÉN** | (ISBN, código_almacén) | ISBN → LIBRO, código_almacén → ALMACÉN |
| **CLIENTE_CESTA** | (IDcesta, correo_electrónico) | IDcesta → CESTA_DE_LA_COMPRA, correo_electrónico → CLIENTE |
