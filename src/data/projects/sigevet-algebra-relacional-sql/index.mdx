## Ejemplo: la división (ejercicio 41)

«Encontrar los medicamentos que están en el inventario de todas las sedes.» El álgebra lo escribe con el operador de división; en SQL no existe, y se expresa al revés: los medicamentos para los que no existe ninguna sede donde falten.

```sql
SELECT m.id_medicamento, m.nombre
FROM MEDICAMENTO m
WHERE NOT EXISTS (
  SELECT s.id_sede FROM SEDE s
  WHERE NOT EXISTS (
    SELECT 1 FROM INVENTARIO i
    WHERE i.id_sede = s.id_sede AND i.id_medicamento = m.id_medicamento));
```

El resultado son 8 medicamentos presentes en las cinco sedes. Los otros dos ejercicios de división usan la misma plantilla con otro conjunto:

| Ejercicio | Qué busca | Filas |
| :-- | :-- | --: |
| 41 | Medicamentos que están en el inventario de todas las sedes | 8 |
| 42 | Veterinarios certificados en todas las especialidades de un conjunto (medicina interna y medicina felina) | 1 |
| 43 | Clientes con facturas en todas las sedes de Bogotá | 6 |

## Ejemplo: lo que MySQL no tiene (ejercicio 29)

El ejercicio 29 compara el inventario de dos sedes por medicamento y muestra también los medicamentos que solo maneja una de las dos: una reunión externa completa. MySQL no trae `FULL OUTER JOIN`, así que se arma con un `LEFT JOIN` y un `RIGHT JOIN` unidos con `UNION`. El resultado tiene 18 filas.

```sql
SELECT a.id_medicamento AS med_usaquen, a.stock_actual AS stock_usaquen,
       b.id_medicamento AS med_chia, b.stock_actual AS stock_chia
FROM (SELECT * FROM INVENTARIO WHERE id_sede = 1) a
  LEFT JOIN (SELECT * FROM INVENTARIO WHERE id_sede = 3) b ON a.id_medicamento = b.id_medicamento
UNION
SELECT a.id_medicamento, a.stock_actual, b.id_medicamento, b.stock_actual
FROM (SELECT * FROM INVENTARIO WHERE id_sede = 1) a
  RIGHT JOIN (SELECT * FROM INVENTARIO WHERE id_sede = 3) b ON a.id_medicamento = b.id_medicamento
ORDER BY COALESCE(med_usaquen, med_chia);
```

## Cómo se verificó

Un script ejecuta las 55 consultas en MySQL y, para cada una, compara el número de filas con el que dio el ejercicio en SQLite, donde se verificó en la Fase 1. El registro de la corrida lista los 55 ejercicios con el conteo de ambos lados y la marca OK, y cierra con el balance de 55 de 55. Es una comparación por número de filas, que es lo que muestra el registro. La aplicación web también ejecuta cada ejercicio por su número, y la ruta elige una de las 55 consultas guardadas sin recibir SQL del navegador.
