## El caso

Huella Sana S.A.S. es una red de clínicas veterinarias inventada para el curso, con cinco sedes (Usaquén, Chapinero, Chía, Laureles y San Fernando), 27 empleados y servicios que van de la consulta y la vacunación a la cirugía, el laboratorio y la hospitalización. Hoy cada sede lleva su agenda, sus historias y su facturación por separado, lo que produce citas cruzadas, historias incompletas, clientes duplicados e ingresos que nadie conoce. El proyecto responde cómo centralizar las cinco sedes en una base clínica, operativa y comercial en tercera forma normal, consultable desde la web.

## Arquitectura

```text
Navegador (Angular) --HTTP 5000 /api--> Controller --> Service --> DAO (JDBC) --> MySQL 8.4 (vet_app)
```

La base corre en una máquina virtual con Oracle Linux 9 y se administra con MySQL Workbench por el puerto 3306. La aplicación es un solo `sigevet.jar` que sirve el frontend y la API por el puerto 5000. Ninguno de los dos puertos se reenvía a Internet.

## Cómo se trabajó

El proyecto se planeó para 14 semanas y cuatro estudiantes, con cuatro hitos: inicio y acta de constitución, validación de la propuesta y la Fase 1 por parte del docente, la Fase 2 (máquina virtual, RDBMS, scripts, aplicación, repositorio y video) y la sustentación con el cierre. El código y la documentación están en un repositorio de GitHub con los aportes de los cuatro integrantes, y los documentos se escriben en Markdown y se convierten a Word. Las herramientas fueron Draw.io y MySQL Workbench para el modelado, Oracle Linux 9 y MySQL 8.4 LTS para el servidor, y Java con Spring Boot y Angular para la aplicación.
