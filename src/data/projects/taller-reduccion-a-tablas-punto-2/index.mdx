## Descripción

Este trabajo corresponde al **Punto 2 del Taller de Reducción a Tablas** de la asignatura **Bases de Datos 1**. El dominio del ejercicio es un espacio zoológico con hábitats y especies, organizado en zonas y atendido por cuidadores y guías que conducen itinerarios de visita.

## Entidades fuertes

| Entidad | Atributos |
|---------|-----------|
| **HÁBITAT** | nombre, clima, vegetación |
| **CONTINENTE** | nombre |
| **ESPECIE** | nombre_científico, descripción, nombre_español |
| **ZONA** | nombre, extensión |
| **CUADOR** | nombre1, nombre2, apellido1, apellido2, calle, carrera, número_dirección, teléfono, ID_cuidador, fecha |
| **ITINERARIO** | nombre_zona, id_itinerario, duración, longitud, visitantes |
| **GUÍA** | nombre1, nombre2, apellido1, apellido2, calle, carrera, número_dirección, teléfono, ID_guía, fecha |

## Entidades asociativas (débiles)

| Entidad asociativa | Atributos | Relacionan |
|--------------------|-----------|------------|
| **HÁBITAT_CONTINENTE** | nombre_hábitat, nombre_continente | HÁBITAT ↔ CONTINENTE |
| **ESPECIE_HÁBITAT** | nombre_científico, nombre_hábitat | HÁBITAT ↔ ESPECIE |
| **CUIDADOR_ESPECIE** | ID_cuidador, nombre_científico, fecha | CUADOR ↔ ESPECIE |
| **ZONA_ITINERARIO** | nombre_zona, id_itinerario | ZONA ↔ ITINERARIO |
| **GUÍA_ITINERARIO** | ID_guía, id_itinerario, hora | GUÍA ↔ ITINERARIO |

## Relaciones del modelo

- **esta_en**: HÁBITAT → HÁBITAT_CONTINENTE (participación 1:N, totalidad (1,1))
- **incluye**: HÁBITAT_CONTINENTE → CONTINENTE (participación (1,1), parcial (0,N))
- **habita / alberga**: HÁBITAT → ESPECIE_HÁBITAT (participación (0,N), totalidad (1,1))
- **vive en**: ESPECIE_HÁBITAT → ESPECIE (participación (1,1), parcial (0,N))
- **está en**: ESPECIE → ZONA
- **forma parte**: ZONA → ZONA_ITINERARIO (participación (0,N), totalidad (1,1))
- **recorre**: ZONA_ITINERARIO → ITINERARIO (participación (1,1), cardinalidad 1:N)
- **recibe cuidado**: ESPECIE → CUIDADOR_ESPECIE (participación (0,N), totalidad (1,1))
- **cuida**: CUIDADOR_ESPECIE → CUADOR (atributo: fecha)
- **es llevado**: ITINERARIO → GUÍA_ITINERARIO (participación (0,N), totalidad (1,1))
- **lleva**: GUÍA_ITINERARIO → GUÍA (atributo: hora)
